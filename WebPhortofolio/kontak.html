Pertanyaan Umum

Apakah saya bisa dipercaya untuk mengerjakan proyek?

Saya selalu mengerjakan proyek secara mandiri dari awal sampai akhir. Untuk proyek freelance saya menyediakan contoh halaman yang sudah selesai agar klien bisa melihat hasilannya.

Teknologi apa saja yang saya kuasai?

Fokus saya adalah HTML5 semantik, CSS3 modern (Flexbox, Grid, custom properties, dan media query), serta JavaScript dasar. Daftar lengkapnya ada di halaman Keahlian.

Apakah tersedia untuk magang part-time?

Ya, saya tersedia untuk magang part-time pada hari-hari kerja setelah jam kuliah, maupun untuk proyek jangka pendek.

Berapa lama pengerjaan satu halaman?

Untuk satu halaman statis sederhana biasanya 3–5 hari kerja, tergantung banyaknya section, ketersediaan konten, dan tingkat responsif yang diminta.

Halaman ini dibuat dengan teknologi apa?

Dibangun dengan HTML semantik, CSS eksternal, dan Flexbox serta CSS Grid untuk layout. Seluruh gaya ditulis di file .css terpisah tanpa style inline.

Lebih mudah kirim email langsung?

Tidak masalah, kirim email dan saya akan membalas secepatnya.
